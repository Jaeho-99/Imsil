## 실행

폴더별로 의존성이 다릅니다. Python 3.11 이상이 필요하며, 한글 그래프에는 맑은 고딕 등 한글 글꼴이 필요합니다.

```bash
# 시계열 분석과 최종 감성 라벨 재생성 (API 키 불필요)
cd 3_감성분석_and_6_시계열분석
pip install -r requirements.txt
python 분석/시계열분석/tierA_seasonal_review_analysis.py
python 분석/감성분석/mixed-final-review/merge_final.py

# 연관관계·요인 분석과 그래프
cd ../4_연관관계분석_and_5_만족-불만요인분석
pip install -r requirements.txt
python analyze_association.py --no-llm     # API 없이 원본 키워드로 계산
python analyze_satisfaction.py --dry-run   # API 없이 대상 집계만
python plot_seasonal_sentiment.py
python plot_seasonal_factors.py
```

- LLM을 호출하려면 `4_.../.env.example`을 `.env`로 복사해 Anthropic API 키를 넣습니다.
- 실행 순서와 **재실행하면 안 되는 스크립트**(사람의 확정 판정을 덮어씀)는 [재현안내](3_감성분석_and_6_시계열분석/재현안내.md)에 있습니다.
- `work/` 스크립트는 `4_...` 폴더를 작업 디렉터리로 두고 실행합니다.
- `2_키워드분석`의 노트북은 Colab용이라 파일 경로를 환경에 맞게 바꿔야 합니다.
- `timeseries_input_audit.py`는 실행한 PC의 절대경로를 `timeseries_input_inventory.csv`에 기록합니다. 재실행한 뒤에는 이 파일을 커밋하지 마세요.

## 데이터 비식별 처리

공개 레포이므로 수집 데이터를 다음과 같이 가공했습니다. 분석 수치는 달라지지 않습니다.

- **리뷰 ID**: 플랫폼의 원본 `reviewId`를 모든 파일에서 동일한 가명(`RV00001` 형식)으로 바꿨습니다.
- **작성자 정보**: 닉네임, 계정 ID, 프로필 URL이 담긴 수집 원본은 포함하지 않습니다.
- **본문 속 개인 이름**: 현장 직원의 실명으로 확인된 표현을 `○○○`로 가렸습니다. 자유 텍스트를 패턴과 문맥으로 점검한 결과이므로 모든 개인정보의 제거를 보장하지는 않습니다.

수집 원본, API 키, 로그인 세션, 내부 보고서는 이 레포에 없습니다. 네이버 집계 스크립트(`1_데이터수집/네이버/visualization.py`)는 수집 원본이 필요하므로 수집기를 먼저 실행해야 합니다. 수집기를 실행하면 작성자 정보가 포함된 파일이 생기며, 이 파일들은 `.gitignore`로 제외됩니다.
