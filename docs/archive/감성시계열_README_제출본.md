## 3. 감성 분석 (보고서 3장)

### 3.1 분석 단위

리뷰 1건에 하나의 감성을 부여하지 않고, 리뷰를 문장 단위로 분리하여 각각을
긍정·중립·부정으로 분류했습니다. 한 리뷰 안에 긍정과 부정 평가가 함께 나타나는
경우가 많아, 관광객이 무엇을 긍정적으로 평가하고 무엇을 부정적으로 평가했는지를
구분하기 위한 선택입니다.

수집 리뷰 5,267건 중 텍스트가 있는 3,208건을 대상으로 하였고, 문장 분리 결과
최종 분석 단위는 5,793개입니다.

### 3.2 방법 선정

세 가지 후보 방법을 검토하고, 사람이 직접 판정한 검증 자료를 기준으로 성능을
비교하여 선정했습니다.

| | 방법 | 결과 |
|---|---|---|
| ① | KNU 감성사전 기반 | 조사 단계에서 제외 — 개선 요구 문장("주차장이 개선되었으면")이 긍정으로 해석되는 문제 |
| ② | 공개 사전학습 모델<br>(`daekeun-ml/koelectra-small-v3-nsmc`) | 비교 수행 |
| ③ | **LLM 분류** | **최종 채택** — macro-F1 0.906 |

**성능을 확인하기 전에 선정 기준을 먼저 확정했습니다.** 주 지표(macro-F1), 중립
판정 임계값, 동률 시 처리 규칙을 사전에 문서로 등록한 뒤 성능을 측정했습니다.
결과를 보고 유리한 방법을 선택하지 않기 위한 절차입니다.

- 사전 등록 문서: `분석/감성분석/calibration/사전등록_임계값.md` (2026-08-21 등록)
- 채점 규칙: `분석/감성분석/evaluation/채점_규칙.md`
- 방법 비교 결과: `분석/감성분석/evaluation/②③_비교.md`

### 3.3 검증 자료와 성능

사람이 직접 판정한 문장 **698개**로 성능을 측정했습니다.

| 자료 | 문장 수 | 용도 |
|---|---|---|
| CAL | 150 | 임계값 결정 (성능 평가에 사용하지 않음) |

## 4. 시계열 분석 (보고서 6장)

### 4.1 분석 범위

리뷰 자료가 충분한 **Tier A 3개소**(붕어섬생태공원, 임실치즈테마파크,
옥정호출렁다리)를 대상으로 2022~2025년 계절별 리뷰 분포와 감성 분포를 분석했습니다.

2026년은 연중 일부 기간만 수집되어 계절 간 비교에서 제외했습니다.
계절 구분은 봄(3~5월) · 여름(6~8월) · 가을(9~11월) · 겨울(12·1·2월)입니다.

임실치즈테마파크는 매년 임실N치즈축제가 개최되는 점을 고려하여,
**축제 직전 14일 / 축제기간 / 축제 직후 14일**의 리뷰 작성량과 감성 분포를
추가로 비교했습니다. 축제기간이 연도별로 4~5일로 달라, 리뷰 작성량은
총량이 아닌 **일평균(건/일)** 을 기준으로 비교했습니다.

## 5. 분석 결과 해석 시 유의사항

보고서 6.6에 기술된 내용과 동일하며, 산출물을 직접 확인하실 때 함께 고려할
사항입니다.

**① 감성 비율은 방문객의 비율이 아닙니다.**
긍정·중립·부정 비율은 분석 대상이 된 **리뷰 문장**의 비율입니다.
방문객 수나 만족한 관광객의 비율로 해석할 수 없습니다.

**② 중립은 만족도가 중간이라는 뜻이 아닙니다.**
해당 문장에 관광지나 방문 경험에 대한 명확한 긍정·부정 평가가 나타나지 않은
경우를 의미합니다.

**③ 일부 시기는 분석 문장 수가 적습니다.**
2025년 축제기간의 분석 대상은 리뷰 5건 · 문장 24개이며, 부정 문장 20개 중
11개가 하나의 리뷰에서 나왔습니다. 소수 리뷰의 영향이 크게 반영될 수 있어,
해당 비율은 그 시기에 확인된 사례로 보는 것이 적절합니다.

**④ 붕어섬생태공원과 옥정호출렁다리는 2022년 10월에 개방·개통되었습니다.**
따라서 2022년 봄·여름 리뷰가 존재하지 않으며, 계절별 집계에 이 운영 이력이
반영되어 있습니다. 리뷰 수 변화 시점과 실제 운영 이력의 대조는
`분석/시계열분석/output/timeline_review_comparison.csv`에 정리했습니다.

**⑤ 리뷰 작성량은 방문객 수와 동일한 지표가 아닙니다.**
계절적 방문 특성, 플랫폼 구성, 주말·공휴일 등 여러 조건이 함께 반영됩니다.
본 분석은 특정 계절이나 축제의 효과를 측정한 것이 아니라, 어느 시기에 리뷰
작성과 긍정·부정 평가가 상대적으로 집중되었는지를 파악한 것입니다.

**⑥ 판정이 어려운 문장 267건은 연구자의 확인을 거친 값입니다.**
전수 분석에서 모델이 하나의 감성으로 판정하지 못한 문장 267건은 전건을 다시
확인하여 라벨을 확정했습니다. 이 중 197건은 LLM의 초벌 판정을 연구자가
검토·동의한 값이고, 30건은 연구자가 직접 판정, 40건은 앞서 표본으로 판정한
건입니다. 따라서 이 267건의 라벨은 **연구자의 독립적 판정이 아니라 확인을 거친
값**으로 해석해야 합니다.

**⑦ 축제 시기별 키워드 비교는 수행하지 않았습니다.**
연도별 축제기간의 분석 대상 리뷰가 2022년 34건, 2023년 8건, 2024년 2건,
2025년 5건으로 편차가 커, 키워드 빈도 비교 시 특정 리뷰 한두 건의 표현이
해당 시기의 특징처럼 나타날 수 있다고 판단하여 분석 범위에서 제외했습니다.

## 6. 분석 단계 번호 (T-1 ~ T-8)

시계열 분석 코드에는 `T-1` ~ `T-8`의 **작업 단계 번호**가 붙어 있습니다. 분석 방법론상의 용어가 아니라, 분석을 수행한 순서를 나타내는 식별자입니다.

각 스크립트의 첫 부분(`파일명: ... (T-5)`)에 해당 번호가 기재되어 있으며,
결과 통합 점검 문서(`분석/시계열분석/시계열_분석_통합점검.md`)도 같은 번호로
단계를 구분합니다. **특정 수치가 어느 단계에서 산출되었는지 추적할 때**
사용하실 수 있습니다.

| 번호 | 단계 | 보고서 |
|---|---|---|
| T-1 | 입력자료 및 연결 기준 점검 | 6.1 |
| T-2 | Tier A 계절별 리뷰 수 | 6.2 |
| T-3 | Tier A 계절별 감성 분포 | 6.3 |
| T4-2 | 외부 공식자료 시점 확인 | 6.1 |
| T-4 | 축제 전·중·후 분석 구간 확정 | 6.1 |
| T-5 | 축제 전·중·후 리뷰 작성량 | 6.4 |
| T-6 | 축제 전·중·후 감성 분포 | 6.5 |
| T-7 | *(수행하지 않음 — 5절 ⑦ 참조)* | — |
| T-8 | 결과 통합 점검 | 6.6 |

## 7. 결과 검증

모든 분석 스크립트는 결과를 저장하기 전에 자체 검사를 수행합니다.
합계 일치, 결합 누락 여부, 다른 단계에서 산출한 수치와의 정합성 등을 확인하며,
검사에 실패하면 그 자리에서 실행을 중단합니다.

마지막 단계(T-8)는 앞선 모든 단계의 산출물을 다시 읽어 **단계 간 수치가 서로
모순되지 않는지 교차 검증**하고, 입력·출력 파일의 MD5 해시를 기록합니다.

검증 결과는 `분석/시계열분석/시계열_분석_통합점검.md`에 있습니다.

> 이 자료의 폴더 구성에서 시계열 분석 전 과정을 재실행하여
> 자체 검사 **87개 항목 전부 통과**를 확인했습니다.
> 재생성된 산출물을 보고서 작성 시점의 결과와 MD5로 대조한 결과,
> **보고서 수치가 담긴 19개 CSV가 모두 완전히 동일**했습니다.

## 9. 중간 산출물에 대하여

`분석/감성분석/` 아래에는 최종 결과와 함께 **분석 과정에서 생성된 중간 자료**가
포함되어 있습니다. 검증 자료 구축, 방법 비교, 전수 적용의 각 단계를 확인하실 수
있도록 남겨둔 것입니다.

**보고서에 수록된 감성 관련 수치는 모두 `fullscale-final/` 에서 산출되었습니다.**
다른 폴더의 파일은 해당 단계의 작업 자료이므로, 보고서 수치와 대조하는 용도로는
사용하지 마십시오.

특히 `분석/감성분석/fullscale/전수_문장라벨.csv`(5,685행)는 판정이 어려운 문장 267건을
전건 확정하기 **이전** 단계의 자료입니다. 최종본(5,793행)이 이를 대체했으며,
입력자료 점검 단계에서 두 자료를 대조하는 데 사용하므로 함께 포함했습니다.
