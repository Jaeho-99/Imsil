# 옛 폴더 → 새 폴더 대응표

2026-11-05 레포를 `src/`·`input/`·`output/` 구조로 정리하면서 옮긴 파일 전체 목록이다.
옛 문서·보고서·커밋에 적힌 경로를 지금 위치로 찾을 때 쓴다. 파일 내용은 바꾸지 않고 옮기기만 했다
(코드는 경로 부분만 고쳤다).

> 옛 폴더에 남은 '내 PC 에만 있는 파일'(수집 원본, `.env`, 구글 로그인 프로필 등)은
> `python src/migrate_old_layout.py` 로 새 위치를 확인하고 `--apply` 로 옮긴다.
