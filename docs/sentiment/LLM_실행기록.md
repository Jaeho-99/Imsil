**run2 는 run1 과 조건이 같아야 한다.** 묶음 크기·순서·프롬프트 중 하나라도 바뀌면
불일치율이 "실행 간 변동성"이 아니라 "변동성 + 조건 차이"가 된다. 무엇을 잰 숫자인지 말할 수 없게 된다.
같은 대화에서 두 번 돌리는 것도 무효다 — 앞 답을 보고 답한다.

주의: 메모리·개인화가 켜져 있으면 새 대화라도 앞 대화를 끌어올 수 있다. 그러면 불일치율이
실제보다 **낮게**(재현성이 좋아 보이는 쪽으로) 나온다. 임시 채팅 권장. 어느 쪽이든 위 표에 적는다.

## 2회 실행 불일치율

| 항목 | 값 |
|---|---|
| **불일치** | **23 / 548 = 4.20%** |
| 실행 간 κ | 0.936 |
| macro-F1 (본 382) | run1 0.906 · run2 0.908 |
| 부정 재현율 (보강 166) | run1 0.910 · run2 0.820 |

**메모리를 끄지 않았으므로 4.20% 는 변동성의 하한이다.** 맥락이 샜다면 두 실행이 더 비슷해지는
방향이기 때문이다. 유출 정황은 관찰되지 않았다 — `?` 를 붙인 문장이 두 실행에서 **한 건도 겹치지 않았고**
(`run1` 3건 · `run2` 4건, 공통 0), `혼합` 판정도 run1만 1건 · run2만 4건으로 갈렸다.
자세한 근거는 `evaluation/③번_재현성.md`.

## 웹 UI의 근본적 재현성 한계

**스냅샷 버전을 못 박을 수 없다.** 웹 UI의 모델은 같은 이름을 유지한 채 제공자 쪽에서 갱신될 수 있고,
사용자는 그 시점을 알 수 없다. 따라서 몇 달 뒤 같은 이름·같은 설정으로 돌려도 같은 결과가 나온다는
보장이 없다. **실행 날짜(2026-08-23)가 이 결과를 특정하는 유일한 좌표다.**

이것은 우리가 잘못한 것이 아니라 웹 UI 실행 경로 자체의 성질이다. 못 지킨 것을 적어 둔다:

| 3강 재현성 요건 | 지켰나 |
|---|---|
| 프롬프트 전문 저장 | 충족 — `프롬프트_v1.md` 동결, 무수정 |
| temperature 0 고정 | 미충족 — 웹 UI라 불가 |
| 모델명·버전 기록 | 부분 충족 — 이름·설정·날짜는 기록. **스냅샷 ID는 공개되지 않음** |
| 2회 실행 불일치율 | 충족 — 4.20% (단, 메모리 미차단이므로 하한) |

보고서 문구:

> ③번 방법은 ChatGPT 웹 UI(모델 표기 ChatGPT 5.6 Sol, 추론 설정 '높음')로 2026-08-23에 실행하였다.
> 웹 UI는 모델 스냅샷 버전을 공개하지 않으며 temperature 를 고정할 수 없으므로, 재현성은 프롬프트를
> 동결한 채 독립된 두 대화에서 각각 실행하고 두 결과의 불일치율로 보고한다(**23/548 = 4.20%**, 실행 간 κ 0.936).
> 두 실행은 동일 모델·동일 설정이었다. 다만 임시 채팅을 사용하지 않아 맥락 유출을 완전히 배제하지 못하며,
> 유출은 불일치율을 낮추는 방향이므로 이 값은 변동성의 하한으로 해석한다.
