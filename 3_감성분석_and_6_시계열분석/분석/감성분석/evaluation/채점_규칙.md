# 채점 규칙

**작성 2026-08-22. 어떤 모델도 아직 실행하지 않은 시점이다.**
이 문서는 **새로 결정하지 않는다.** 이미 확정된 규칙을 한곳에 모으고 출처를 단다.
새로 들어간 값은 다수 클래스 기준선 하나뿐이고, 그것은 선택이 아니라 사람 라벨에서 센 값이다.

## 채점 대상

| 구분 | 문장 | 무엇을 재나 | 출처 |
|---|---:|---|---|
| CAL | 150 | ②번 중립 임계값 결정 **전용**. 성능 보고에 일절 쓰지 않는다 | `calibration/사전등록_임계값.md` |
| TEST 본 | 382 | macro-F1 · 정확도 · 클래스 분포 | 〃 |
| TEST 보강 | 166 | **부정 재현율만** (부정 89문장) | `learning-records/0004` |
| 채점 합계 | 548 | 보고서에 이 숫자를 명시한다 | |

**두 세트의 수치를 합치지 않는다.** 합치면 분포가 왜곡되어 macro-F1도 정확도도 못 쓴다.
표기: "전체 성능은 TEST 본 382문장, 부정 재현율은 보강셋 166문장에서 별도 측정."

## 정렬

- 확정 CSV의 `sent` 열을 **그대로** 모델 입력으로 넣는다. **평가 단계에서 문장을 다시 분리하지 않는다.**
  다시 분리하면 정답과 예측의 단위가 어긋나 1:1 대응이 깨진다.
- 정답·예측은 `unit_id`로 붙인다. 행 순서에 의존하지 않는다.
- 예측 수가 정답 수와 다르면 채점을 중단한다. 빈 예측을 중립으로 메우지 않는다.

## 지표

- **주 지표: macro-F1.** 긍정·중립·부정 각각의 F1을 구해 **산술평균**한다(가중 없음).
  precision·recall의 분모가 0이면 그 값을 0으로 두고, F1의 분모가 0이면 F1을 0으로 둔다.
- **보조 지표: 부정 클래스 재현율.** TEST 보강 166문장에서 잰다.
- **정확도는 단독으로 쓰지 않는다.** 항상 다수 클래스 기준선과 나란히 적는다.
  근거: 파일럿에서 부정 재현율 0.375로 무너진 모델의 정확도가 0.806이었다(`learning-records/0004`).
- micro-F1·weighted-F1은 쓰지 않는다. 단일라벨 다중분류에서 micro-F1은 정의상 정확도와 같다.
- sklearn 없이 혼동행렬 산술로 직접 계산한다(`learning-records/0008`).

## 다수 클래스 기준선

| | 값 | 근거 |
|---|---:|---|
| 파일럿 추정 (LLM 라벨 62문장) | 0.661 | `learning-records/0004` |
| **확정 (사람 라벨 TEST 본 382문장)** | **0.579** | `evaluation/rating_vs_label.py` |

파일럿 추정치는 LLM이 매긴 라벨에서 나온 값이라 폐기하고, 사람 라벨로 갱신했다.
②·③이 정확도 0.579를 못 넘으면 2강 4순위 규칙이 발동한다 —
**채택하지 않고 그 사실을 결과로 보고한다.**

## 비교 대상

① 사전 기반(KNU)은 **실행하지 않는다.** 제외 결정과 그 근거를 방법론 절에 쓴다(`learning-records/0008`).
비교는 ② 공개 사전학습 모델 무학습 적용 · ③ LLM 두 방법.

## 하지 않는 것

- **결과를 본 뒤 임계값·지표·분모를 바꾸지 않는다.** ②번 중립 밴드 `t`는
  CAL 150문장에서 사전 등록된 절차로 한 번 정하고, TEST 수치를 본 뒤 손대지 않는다.
- **정답 라벨을 고치지 않는다.** 모델과 사람이 다를 때 그 불일치가 곧 성능 측정값이다.
  고치는 순간 해당 방법의 점수가 부풀려진다.
- **감성사전 어휘로 정답을 다시 훑지 않는다.** 훑는 순간 그 방식에 유리해진다.
- 임계값별 macro-F1 곡선은 부록에만 싣는다.

## 신뢰도

정답셋은 1인 단독 라벨이다(`learning-records/0002`). 근거는 하루 뒤 무작위 50문장 재라벨의
Cohen's κ 하나뿐이다(`labeling/재라벨/`). κ와 함께 **재라벨까지의 실제 간격을 시간 단위로 밝힌다.**
간격이 짧으면 κ는 상한값이다.
