# 수동 다운로드 파일 넣는 곳

언급량·게시물은 검색 API(scripts/01)로 받고, 나머지는 웹 화면에서 내려받은 파일을 아래 폴더에 넣고 `python scripts/05_analyze.py` 를 실행한다.
결과는 `data/processed/online_buzz/<API 수집일 또는 manual_YYYYMMDD>/` 에 `M_` 로 시작하는 이름으로 저장된다.

**파일명 규칙**: `다운로드일_내용_조건.확장자` (예: `20261109_시군비교_월간_2022-2026__anchor=임실.xlsx`).
다운로드일과 조건(기간, 단위, 기기·성별·연령 필터)을 파일명에 남겨야 보고서에 수집 기준을 정확히 적을 수 있다.

## naver_datalab/ — 네이버 데이터랩 검색어트렌드

- 출처: https://datalab.naver.com > 검색어트렌드 > 조회 후 '다운로드'(엑셀)
- 원본 .xlsx 그대로 넣는다(손대지 않음). .csv 로 저장한 것도 읽는다.
- 한 번에 주제어 5개까지만 비교되고 값은 '조회 안 최대값=100' 인 상대값이다.
  **5개가 넘는 그룹(예: 전북 14개 시군)을 한 척도로 비교하려면** 모든 조회에 같은 기준 주제어(예: 임실)를 넣고
  파일명에 `__anchor=임실` 을 붙인다. 05_analyze 가 기준 주제어 평균=100 으로 맞춘 `M_datalab_index_anchor-임실.csv` 를 만든다.
- 권장 조회 세트
  주제어 이름과 넣는 검색어는 `config/키워드사전_v*.csv` 의 '주제어'·'넣는 검색어' 를 그대로 쓴다('쓰는 곳'에 검색추이가 있는 행).
  1. 시군 비교: 주제어 = 임실 + 다른 시군 4개 (×4회), 월간, 2022-01~2026-10, `__anchor=임실`
  2. 임실 관광지·축제·특산물: 주제어 = 임실 + 다른 주제어 4개씩, `__anchor=임실`
  3. 같은 조회를 기기(PC/모바일)·성별·연령 필터별로 한 번씩 (파일명에 필터 명시)
  4. 축제 전후 분석용 일간 조회

## naver_searchad/ — 네이버 검색광고 키워드도구

- 출처: https://searchad.naver.com > 도구 > 키워드 도구 > 키워드 입력(최대 5개) 후 '다운로드'
- 원본 그대로 넣고, 파일명에 넣은 키워드를 `__seed=` 로 적는다(여러 개는 `+`). 예) `20261107_키워드도구__seed=임실여행+임실가볼만한곳.xlsx`
- 값은 조회일 기준 최근 30일 검색수다. '< 10' 은 5 로 바꾸고 censored_lt10 열에 표시한다.

## keyword_check/ — 검색어 정확도 확인표

`python scripts/00_keyword_check_sheet.py make` 가 만든 확인표가 여기 저장된다. 엑셀로 열어 '맞음' 열에 O/X 를 적고
`summarize` 로 확인결과를 만든다. X 가 20건 중 3건을 넘는 검색어는 키워드 사전에서 좁힌다.

## google_trends/ — Google Trends

- 출처: https://trends.google.co.kr > 탐색 > 지역 '대한민국'(또는 전북), 기간 지정 > 각 차트의 다운로드(CSV)
- '시간 흐름에 따른 관심도' CSV 는 아무 이름으로, '관련 검색어' CSV 는 파일명에 `related` 를 넣는다
  (예: `20261109_KR_임실_related.csv`).

## mentions/ — 언급 건수와 게시물 텍스트

직접 집계했거나 다른 도구(예: 네이버 블로그 검색 결과 수 확인, 썸트렌드 등)에서 내려받은 결과를 아래 형식으로 정리한다.
열 이름만 맞으면 열 순서와 추가 열은 상관없다. `_template_*.csv` 를 복사해서 쓰면 된다.

| 파일명 | 필수 열 | 선택 열 | 쓰임 |
|---|---|---|---|
| `mention_counts*.csv` | region(시군), channel(blog/cafe/news 등), count | query, period, source, collected_at | 시군별 언급량·전북 내 비중 |
| `posts*.csv` | channel, title, text(본문 또는 요약) | date(YYYY-MM-DD), link, query | 시군 언급률, 키워드 빈도·TF-IDF, 연관규칙·네트워크 |
