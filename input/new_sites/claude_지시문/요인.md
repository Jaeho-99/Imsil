# 지시문 — 추가 관광지 만족·불만 요인 판정

이 파일을 받은 Claude는 **어노테이터**입니다. 추가 관광지 2개소의 리뷰마다 (요인 카테고리, 원문 구절, 평가 표현, 극성)을 뽑습니다.
34개소 보고서 5장의 요인 판정과 같은 프롬프트를 씁니다. 34개소 때도 Claude Code 대화에서 같은 방식으로 판정했습니다.

## 규칙

1. **판정 기준은 프롬프트 하나입니다.** 프롬프트를 고치거나 기준을 더하지 않습니다. 34개소 판정 결과(`input/satisfaction/`, `output/satisfaction/`)는 열지 않습니다.
2. **판정은 직접 리뷰를 읽고 합니다.** 키워드·사전·규칙으로 요인을 붙이는 코드를 만들지 않고, API나 다른 모델을 부르지 않습니다. 판정한 줄을 파일에 덧붙이는 데 도구를 쓰는 것은 괜찮습니다.
3. **span과 opinion은 리뷰 본문에 있는 글자를 그대로 옮깁니다.** 요약·변형·맞춤법 교정을 하지 않습니다 (공백·줄바꿈 차이는 괜찮습니다).

## 읽는 파일

| 파일 | 쓰임 |
|---|---|
| `output/new_sites/satisfaction/판정프롬프트.txt` | 판정 기준. 34개소 `src/satisfaction/analyze_satisfaction.py`의 `SYSTEM_PROMPT`를 글자 그대로 옮긴 것입니다 |
| `output/new_sites/satisfaction/판정대상.jsonl` | 판정할 리뷰. 한 줄에 리뷰 하나: `{"i": 번호, "rid": 리뷰ID, "h": 본문 확인값, "place": 관광지, "body": 본문}` |
| `input/new_sites/satisfaction/annotations.jsonl` | 지금까지 쓴 판정 (이어서 할 때) |

두 output 파일이 없으면 `python src/new_sites/satisfaction.py export`를 먼저 실행합니다.

## 쓰는 형식

`input/new_sites/satisfaction/annotations.jsonl`에 리뷰 하나당 한 줄을 씁니다.

```json
{"rid": "RV10001", "h": "1a2b3c4d", "o": "POS", "f": [["경관·볼거리", "풍경이 너무 예쁘고", "예쁘고", "POS"], ["접근·주차", "주차장이 좁아요", "좁아요", "NEG"]]}
```

| 키 | 값 |
|---|---|
| `rid`, `h` | `판정대상.jsonl`의 값을 그대로 옮깁니다 |
| `o` | 리뷰 전체 극성 (`overall_sentiment`): `POS`·`NEG`·`NEU` |
| `f` | 요인 목록 (`factors`). 요인 하나는 `[카테고리, span, opinion, 극성]`이고, 판정할 요인이 없으면 `[]`입니다 |

- 카테고리는 프롬프트의 12종과 `대상외` 중 하나를 글자 그대로 씁니다 (가운뎃점 `·` 포함).
- 극성은 `POS`·`NEG`·`NEU` 중 하나입니다.
- 프롬프트가 말하는 출력(`factors`의 `category`·`span`·`opinion`·`sentiment`, `overall_sentiment`)을 위 줄 형식으로 옮겨 적은 것입니다.

## 하는 일

1. 프롬프트를 읽습니다.
2. `python src/new_sites/satisfaction.py check`로 남은 리뷰 번호를 확인합니다. 처음이면 전부 남아 있습니다.
3. `판정대상.jsonl`을 `i` 순서로 25건씩 읽고 판정해, 판정 파일 끝에 덧붙입니다. 이미 있는 줄은 지우지 않습니다.
4. 25건마다 `python src/new_sites/satisfaction.py check`를 실행합니다. 오류가 나온 줄은 그 줄만 고칩니다.
   - `span 이 본문에 그대로 없음`: 본문에서 글자를 다시 옮겨 적습니다.
   - `두 번 나옴`: 한 줄만 남깁니다.
   - `본문 확인값 h 가 다름`: `판정대상.jsonl`의 `h`를 옮겨 적습니다. 리뷰 본문이 바뀐 경우(다시 수집했거나 실명을 가린 경우)에는 리뷰를 다시 읽고 판정을 고칩니다.
5. 남은 리뷰가 0건이 될 때까지 3~4를 반복합니다. 대화가 길어지면 새 대화에서 이 지시문을 다시 받아 2번부터 이어 갑니다.
6. 끝나면 사용자에게 알리고, check 결과(판정 N/N건, 오류 0건)를 한 줄로 전합니다. 집계(`satisfaction.py merge`)는 사람이 실행합니다.
