# 지시문 — 추가 관광지 외국어 리뷰 번역

`preprocess.py`가 외국어 리뷰를 찾으면 `output/new_sites/번역대상.csv`를 만듭니다. 이 파일이 없으면 번역할 리뷰가 없는 것이므로 할 일이 없습니다.
(2026-11 수집분에는 외국어 리뷰가 없습니다.)

## 읽는 파일

`output/new_sites/번역대상.csv` — 열: `reviewId`, `원문`

## 번역 원칙

예전 API 번역 단계에서 쓰던 지시와 같습니다.

- 한국 관광지에 대한 외국어 리뷰입니다. 한국어로 자연스럽게 번역합니다.
- 뜻을 더하거나 빼지 말고, 평가의 강도와 말투를 살립니다.
- 고유명사(지명·인명)는 한국어 표기로 옮깁니다.
- 줄바꿈은 원문대로 유지합니다.
- 번역문만 씁니다. 설명·따옴표·머리말을 붙이지 않습니다.

## 쓰는 형식

`input/new_sites/번역결과.csv`에 씁니다 (UTF-8, 이미 있으면 기존 행은 두고 행을 덧붙입니다).

| 열 | 값 |
|---|---|
| `reviewId` | 번역대상의 값 그대로 |
| `원문` | 번역대상의 `원문`을 글자 그대로 (코드가 지금 본문과 같은지 대조합니다) |
| `번역` | 번역문 |
| `방법` | `Claude Code (모델 이름, YYYY-MM-DD)` |

CSV 칸에 쉼표·줄바꿈·따옴표가 있으면 큰따옴표로 감쌉니다. 손으로 쓰기보다 Python의 `csv` 모듈이나 pandas로 쓰는 편이 안전합니다(번역문은 직접 작성합니다).

## 끝나면

`python src/new_sites/preprocess.py`를 실행해 `외국어 리뷰 번역` 검사가 `미번역 0`인지 확인하고 사용자에게 알립니다.
번역이 들어가면 본문이 바뀌므로 그 뒤 단계(키워드·감성·요인)는 다시 실행해야 합니다.
